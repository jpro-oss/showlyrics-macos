📖 Detailed User Manual

Informasi Penting: Aplikasi ShowLyrics menggunakan teknologi Web-Hybrid. Anda dapat membuka layar proyektor dari komputer (atau HP) mana saja yang terhubung di jaringan WiFi yang sama!

⚠️ PERSIAPAN WAJIB (CHROME SITE SETTINGS)

Agar font lokal Windows (Native Fonts) dan fitur copy-paste berjalan sempurna, Anda WAJIB memberikan izin (Permissions) pada browser Chrome Anda:

  1. Buka tab baru di Chrome, lalu copy-paste URL pengaturan khusus ini:

    chrome://settings/content/siteDetails?site=http%3A%2F%2F127.0.0.1%3A18888

  2. Pada halaman yang terbuka, cari pengaturan Fonts (Fonta), lalu ubah dari Block/Ask menjadi Allow (Izinkan).
  3. Cari juga pengaturan Clipboard (Papan Klip), lalu ubah menjadi Allow (Izinkan).
  4. Tutup halaman pengaturan tersebut, dan tekan F5 untuk me-refresh tab ShowLyrics Anda.

Bab 1: Persiapan & Import Lagu

  1. Upload File TXT: Gunakan tombol Import di sebelah kotak pencarian Library, lalu pilih file .txt berisi lirik Anda.
  2. Format Teks & Enter Ganda: Server membaca baris kosong (jeda enter 2 kali) di dalam file teks sebagai instruksi "Pisahkan ini menjadi slide baru". Pastikan ada jarak antar bait di file TXT Anda.
  3. Lirik Bilingual (Dua Bahasa): Ketik simbol // di tengah lirik. Contoh: Kudus//Holy. Aplikasi akan memisahkan baris kedua menjadi terjemahan.
  4. Menyimpan Lagu Baru: Setelah selesai mengedit teks di kolom Editor, tombol Save akan berkedip kuning. Klik tombol tersebut untuk menyimpannya ke database komputer.
  5. Menghapus Lagu di Library: Klik ikon tong sampah berwarna merah di tab Library.
  6. Proteksi Hapus: Aplikasi akan memunculkan dialog konfirmasi agar Anda tidak menghapus lagu secara tidak sengaja.

Bab 2: Manajemen Jadwal / Rundown

  1. Menambah ke Jadwal: Klik tombol panah + di samping nama lagu, atau drag lagu tersebut ke area Playlist (Schedule).
  2. Mengurutkan Lagu: Klik tahan dan geser kartu lagu di area Schedule ke atas atau bawah sesuai rundown acara.
  3. Menghapus dari Jadwal: Menekan tanda silang di Schedule hanya menghapus lagu dari daftar acara, BUKAN menghapusnya dari database komputer Anda.
  4. Export Bundle (ZIP): Klik tombol 'Export Bundle' untuk membungkus seluruh setlist hari ini (beserta data lagunya) menjadi file .zip. Cocok untuk memindahkan jadwal ke laptop gereja lain.
  5. Import Bundle: Buka file ZIP hasil Export dengan fitur Import Bundle.
  6. Proteksi Duplikat: Saat Anda melakukan Import Bundle, aplikasi tidak akan menduplikat lagu (contoh: Lagu "Besar SetiaMu 1" dan "Besar SetiaMu 2"). Sistem cerdas akan menimpa DNA lagu lama dengan data dari file ZIP.

Bab 3: URLs Output & Sistem Layar

Buka browser di HP/Tablet yang satu WiFi, dan ketik IP Laptop VJ (contoh: http://192.168.1.10:18888/foldback). Layar akan tampil tanpa kabel!

  1. URL Main Display (/display): Layar ini untuk jemaat/audiens. Letakkan *window* ini di monitor Proyektor.
  2. Fullscreen Proyektor: Setelah memindahkan window Main Display ke layar proyektor, klik sekali layarnya, lalu tekan F11 di keyboard untuk mode layar penuh.
  3. URL Lower Third (/lowerthird): Copy URL ini dan masukkan ke "Browser Source" di dalam OBS Studio atau vMix untuk keperluan Livestreaming.
  4. Alpha Channel OBS: Tidak perlu repot Color/Chroma Key! Lower Third sudah terprogram transparan (Alpha) otomatis.
  5. URL Foldback (/foldback): Layar monitor untuk penyanyi di panggung (Singer/WL).
  6. Format Foldback: Foldback sengaja berlatar hitam kontras tinggi. Tulisan besar di tengah adalah baris saat ini, tulisan kecil di bawah adalah baris lagu selanjutnya.

Bab 4: Controller & Live Eksekusi

  1. Menembak Slide: Klik kotak lirik mana saja di panel tengah Controller, lirik akan langsung muncul di Proyektor.
  2. Clear Layar (Eject): Klik kotak hitam kosong pertama (sebelum lirik dimulai) atau tombol Clear untuk mematikan lirik tanpa mereset urutan jalan Anda.
  3. Quick Edit Teks: Penyanyi salah lirik? Klik Kanan kotak lirik yang sedang tayang, ubah teksnya, dan layar proyektor akan berubah instan tanpa perlu menekan Save!
  4. Tombol Jump Shortcut: Malas menggunakan Mouse? Tekan V (Verse), C (Chorus), atau B (Bridge) di keyboard. Kursor akan otomatis melompat ke bagian tersebut.
  5. Fast Slide Tagging: Tahan tombol SHIFT dan tekan V (Biru) atau C (Merah) saat menyeleksi blok teks untuk menandai warna Chorus/Verse dengan super cepat.
  6. Auto-Scroll View: Saat Anda mengklik lirik, layar Controller otomatis akan sedikit turun (scroll) agar lirik aktif selalu berada di posisi tengah pandangan Anda.

Bab 5: Komunikasi Panggung (Stage Control)

  1. Stage Message: Ketik instruksi (contoh: "Masuk Cello Saja") di kotak pesan dan kirim. Pesan ini HANYA tampil di layar Foldback panggung, jemaat tidak akan tahu.
  2. Mode Blink (Kedip): Centang kotak 'Blink' sebelum mengirim Stage Message untuk membuat tulisan tersebut berkedip merah (untuk tanda darurat/habis waktu).
  3. Stage Countdown: Atur waktu menit/detik dan mulai timer. Hitung mundur digital besar akan muncul di monitor penyanyi/pembicara.
  4. Audience Alert: Berbeda dengan Stage Message, Alert ini adalah "Running Text" (Teks Berjalan) untuk mengumumkan pesan darurat (misal plat nomor mobil) ke layar Utama Jemaat.
  5. Pengaturan Speed Alert: Geser slider Speed Alert sebelum menyalakan running text untuk menyesuaikan seberapa cepat teks berjalan melintas layar. Kecepatannya konstan dan linear.

Bab 6: Tema Visual & Text Editor

  1. Custom DNA Editor: Buka Text Editor dari panel kontrol lagu. Perubahan Background dan Font yang Anda simpan di sini menjadi "DNA" mutlak untuk lagu itu saja.
  2. Song Preset Editor: Ubah *dropdown* mode ke "Preset". Anda bisa membuat 1 tema desain dan menyimpannya ke database untuk dipasang ke puluhan lagu sekaligus.
  3. Global Edit Preset: Mau ubah warna teks sebuah Preset? Klik Kanan kartu Preset di tab Visual (sebelah kiri Controller) lalu pilih Edit.
  4. Draft Protection: Jika saat mengedit tema Anda berubah pikiran dan memencet tanda silang ✖, sistem akan mengembalikan tampilan Proyektor ke kondisi semula berkat memori Snapshot.
  5. GPU Text FX: Pilih animasi transisi Fade, Stagger (Naik per huruf), atau Wave. Proses animasi murni digerakkan oleh GPU Komputer, bukan RAM.
  6. Global Sub Settings: Buka tab Global Settings untuk mengatur warna, jarak, dan ukuran font khusus untuk bahasa terjemahan (Bilingual).
  7. Font Windows Lokal: Tuliskan nama font apa pun yang sudah terinstal di Windows Anda (Misal: 'Montserrat' atau 'Times New Roman') di kolom Font Name Editor.

Bab 7: Keamanan Lisensi & Sistem Hardware

  1. Sistem Offline: ShowLyrics bisa berjalan 100% tanpa internet, KECUALI saat pertama kali aktivasi License Key.
  2. Hardware ID Lock: Lisensi Anda diikat ke Hardware PC secara mutlak (dicatat di Server). Jika ingin pindah PC, Anda wajib menekan 'Release/Deactivate' saat online.
  3. Halaman Diagnostics: Buka Diagnostics via Launcher untuk memeriksa 'kesehatan' file-file JSON Anda. Jika ada file JSON yang korup, statusnya akan merah.
  4. Pantau RAM (Memory Check): Halaman Diagnostics juga menampilkan indikator persentase beban CPU dan RAM komputer PC Anda untuk menghindari resiko *lag* saat acara live.
  5. Virtual Chunk Limit: Jangan takut memasukkan 3000 lagu ke Library! Sistem menggunakan Lazy Loading Virtual Chunking, sehingga RAM browser Anda akan selalu hemat dan gesit.
  6. Safe Restart Server: Jika Backend Python ter-close, Controller HTML tidak perlu di-refresh ulang. Cukup nyalakan server `main.py` lagi dan WebSocket akan tersambung kembali (Auto-Reconnect).
Important Note: ShowLyrics uses Web-Hybrid technology. You can open projector displays from any laptop, phone, or tablet connected to the same local WiFi!

⚠️ CRUCIAL SETUP (CHROME SITE SETTINGS)

To ensure local Windows fonts and the copy-paste clipboard functions work flawlessly, you MUST grant permissions in your Chrome browser:

  1. Open a new tab in Chrome, and copy-paste this direct settings URL:

    chrome://settings/content/siteDetails?site=http%3A%2F%2F127.0.0.1%3A18888

  2. On the settings page, find the Fonts permission and change it to Allow.
  3. Find the Clipboard permission and change it to Allow.
  4. Close the settings tab and press F5 to refresh your ShowLyrics tab.

Chapter 1: Song Import & Preparation

  1. TXT File Upload: Use the Import button next to the Library search box, then select your .txt lyric file.
  2. Double Enter formatting: The server reads empty lines (double enter breaks) in your text file as an instruction to "split into a new slide". Ensure paragraphs are separated.
  3. Bilingual Lyrics: Type the // symbol in the middle of a lyric. Example: Kudus//Holy. The app splits the second line as a translation subtitle.
  4. Saving New Songs: After editing text in the Editor column, the Save button will flash yellow. Click it to save changes to the local computer database.
  5. Deleting Songs: Click the red trash bin icon in the Library tab.
  6. Delete Protection: A confirmation dialog will pop up to prevent accidental deletion of your lyric data.

Chapter 2: Schedule / Rundown Management

  1. Adding to Schedule: Click the + button next to a song, or drag it into the Playlist (Schedule) area.
  2. Sorting the Schedule: Click, hold, and drag song cards up or down to arrange your event rundown.
  3. Removing from Schedule: Clicking the cross icon in the Schedule only removes the song from the event list, NOT from your main database.
  4. Export Bundle (ZIP): Click 'Export Bundle' to pack today's setlist (including all its song data) into a .zip file. Perfect for transferring to another church laptop.
  5. Import Bundle: Open exported ZIP files using the Import Bundle feature.
  6. Duplicate Protection: When importing a Bundle, the system prevents duplicate songs (e.g., "Great is Thy Faithfulness 1" and "2"). It intelligently overwrites old song DNA with data from the ZIP.

Chapter 3: Output URLs & Screen Systems

Open a browser on a phone/tablet on the same WiFi, and type the VJ Laptop's IP (e.g., http://192.168.1.10:18888/foldback). Wireless display achieved!

  1. Main Display URL (/display): This screen is for the audience. Move this window to your Projector monitor.
  2. Projector Fullscreen: After moving the Main Display window, click it once, then press F11 for fullscreen mode.
  3. Lower Third URL (/lowerthird): Copy this URL and paste it as a "Browser Source" inside OBS Studio or vMix for Livestreaming.
  4. OBS Alpha Channel: No Chroma Key needed! Lower Third is pre-programmed to be automatically transparent (Alpha channel).
  5. Foldback URL (/foldback): The stage monitor display for singers and worship leaders.
  6. Foldback Format: Foldbacks have a high-contrast black background. Large text is the current line, small text below is the upcoming line.

Chapter 4: Controller & Live Execution

  1. Triggering Slides: Click any lyric box in the central panel, and the text will instantly appear on the Projector.
  2. Clear Screen (Eject): Click the first empty black box (before the lyrics) or the Clear button to hide lyrics without losing your current timeline position.
  3. Quick Text Edit: Did the singer sing a wrong word? Right-Click the active lyric box, edit the text, and the projector updates instantly in realtime without hitting save!
  4. Jump Shortcut Keys: Hate using the mouse? Press V (Verse), C (Chorus), or B (Bridge) on your keyboard to snap the cursor to that song section.
  5. Fast Slide Tagging: Hold SHIFT and press V (Blue) or C (Red) while highlighting text blocks to color-tag them super fast.
  6. Auto-Scroll View: As you trigger lyrics, the Controller panel automatically scrolls down to keep the active lyric in the center of your view.

Chapter 5: Stage Control & Communication

  1. Stage Message: Type an instruction (e.g., "Cello Solo") and send it. This message ONLY appears on the Foldback monitor, hidden from the audience.
  2. Blink Mode: Check the 'Blink' box before sending a Stage Message to make the text flash red (used for urgent/time-out warnings).
  3. Stage Countdown: Set the minutes/seconds and start the timer. A large digital countdown will inject into the speaker's monitor.
  4. Audience Alert: Unlike Stage Messages, the Alert is a "Running Text" scroll to broadcast emergency messages (like a car license plate) to the main audience display.
  5. Alert Speed Setting: Adjust the Speed Alert slider before launching running text to set the linear scrolling speed.

Chapter 6: Visual Themes & Text Editor

  1. Custom DNA Editor: Open the Text Editor from a song's control panel. Background and Font changes saved here become the absolute "DNA" for that specific song only.
  2. Song Preset Editor: Switch the editor mode to "Preset". Create one design theme and save it to the database, applying it to dozens of songs instantly via dropdown.
  3. Global Preset Edit: Want to change a Preset's color globally? Right-Click the Preset card on the left panel and select Edit.
  4. Draft Protection: If you change your mind during editing and hit the close ✖ button, the system rolls back the Projector output to its original state via Snapshot Memory.
  5. GPU Text FX: Choose Fade, Stagger, or Wave transitions. Animation calculations are purely driven by your GPU, keeping system RAM free.
  6. Global Sub Settings: Open the Global Settings tab to configure specific colors, padding, and sizes exclusively for translated (Bilingual) text.
  7. Local Windows Fonts: Type the name of any font installed on your PC (e.g., 'Montserrat' or 'Impact') in the Font Name field, and it will render perfectly.

Chapter 7: License Security & System Hardware

  1. Offline System: ShowLyrics runs 100% offline without internet, EXCEPT during the initial License Key activation.
  2. Hardware ID Lock: Your license is strictly bound to your PC's Hardware ID via Cloud. To move PCs, you must click 'Release/Deactivate' while online.
  3. Diagnostics Page: Open Diagnostics from the Launcher to run a 'health check' on your JSON files. Corrupted files will flag red immediately.
  4. RAM Monitoring: The Diagnostics page also displays live CPU load and RAM percentage to prevent live-event stutters.
  5. Virtual Chunk Limit: Don't worry about loading 3000 songs! The system uses Lazy Loading Virtual Chunking, keeping your browser RAM incredibly low and responsive.
  6. Safe Server Restart: If the Python backend closes, you don't need to refresh the HTML Controller. Just restart `main.py` and the WebSocket auto-reconnects seamlessly.
